# 🏔️ RIMA (Rinjani Digital Asset) Web

> **Mendagitalisasi Sektor Hospitality Lombok Melalui Talenta Kreatif & Data Lokal Mataram.**

RIMA (Rinjani Digital Asset) adalah platform web yang dirancang untuk memberdayakan talenta desain dan data di Mataram. Platform ini menjembatani kreator lokal dengan pemilik usaha *hospitality* skala menengah di Lombok, memungkinkan mereka melakukan transformasi digital secara mandiri tanpa harus bermigrasi ke pusat industri seperti Bali atau Jawa.

---

## 🎯 Objektif Proyek
Memberdayakan ekosistem talenta UI/UX dan Data Science di Mataram untuk menyediakan aset digital siap pakai yang disesuaikan khusus dengan kebutuhan fasilitas populer (*Wi-Fi Gratis, Kolam Renang, Sarapan Gratis*) pada bisnis *hospitality* lokal Lombok.

---

## 🔑 Key Results & Target
* **KR 1 (Suplai):** Menghasilkan **15 template UI/UX** dan dasbor **Looker Studio** terintegrasi yang dioptimalkan untuk pengelolaan fasilitas properti.
* **KR 2 (Permintaan):** Mencapai **12 unduhan aset digital berbayar** dari properti lokal yang terdaftar dalam dataset.
* **KR 3 (Otomasi Teknis):** Mengotomatisasi ekstraksi data harga dan fasilitas (CSV) menggunakan pipeline **Langflow** untuk menghasilkan **50 brief tantangan komunitas (Community Challenge)**.

---

## 🛠️ Tech Stack & Alat
* **Frontend / Web:** HTML, CSS, JavaScript / React (sesuai framework proyek)
* **Data Visualization:** Looker Studio
* **Data & Automation Pipeline:** Langflow, Python (CSV Processing)
* **Design & Assets:** UI/UX Template Kits

---

## 🚀 Fitur Utama
1. **Digital Asset Marketplace / Showcase:** Katalog template UI/UX dan dasbor Looker Studio khusus bisnis *hospitality*.
2. **Automated Challenge Brief Generator:** Pipeline berbasis Langflow yang memproses dataset CSV properti lokal menjadi brief *Community Challenge* bagi talenta desain/data.
3. **Local Property Dataset Integration:** Dataset yang memetakan fasilitas dan penetapan harga properti di Lombok.
